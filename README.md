# ML Exercises

This repository contains a collection of machine learning exercises and projects. Each notebook focuses on different aspects of machine learning, such as clustering, regression, classification, and more. The exercises are developed in Google Colab and provide hands-on practice for various ML techniques.

## Directory

Below is a list of the exercises and their corresponding notebooks:

- [**Clustering.ipynb**](./Clustering.ipynb): This notebook explores clustering techniques, including k-means and hierarchical clustering.
- [**Linear_Regression_one_variable.ipynb**](./Linear_Regression_one_variable.ipynb): A practical introduction to linear regression with one variable.
- [**Linear_Regression.ipynb**](./Linear_Regression.ipynb): Expands on linear regression with multiple variables and feature scaling.
- [**Regularization.ipynb**](./Regularization.ipynb): Demonstrates L1 (Lasso) and L2 (Ridge) regularization to prevent overfitting in regression models.
- [**Classification.ipynb**](./Classification.ipynb): Introduces classification models such as logistic regression and performance evaluation metrics.
- [**Decision_Tree.ipynb**](./Decision_Tree.ipynb): Explains decision tree algorithms and their application to classification problems.
- [**SVM.ipynb**](./SVM.ipynb): A comprehensive guide to support vector machines for classification.
- [**Neural_Networks_Part_I.ipynb**](./Neural_Networks_Part_I.ipynb): Covers the basics of neural networks, including perceptrons and feedforward networks.
- [**Neural_Networks_Part_II.ipynb**](./Neural_Networks_Part_II.ipynb): Explores activation functions, gradient descent, and backpropagation.
- [**Neural_Networks_Part_III.ipynb**](./Neural_Networks_Part_III.ipynb): Focuses on advanced topics like deep learning architectures and optimization techniques.
- [**Recommendation_System.ipynb**](./Recommendation_System.ipynb): Demonstrates the implementation of recommendation systems using collaborative filtering.
- [**Diabetes_Prediction.ipynb**](./Diabetes_Prediction.ipynb): A classification project predicting diabetes using logistic regression.
- [**Economic_Growth_Prediction.ipynb**](./Economic_Growth_Prediction.ipynb): Uses machine learning models to predict economic growth for developing countries.
- [**Global_Temperature_Prediction.ipynb**](./Global_Temperature_Prediction.ipynb): Focuses on predicting global temperature changes using time series analysis.


## How to Use

1. Clone the repository:
   ```bash
   git clone git@github.com:your-username/ml-exercises.git
    ```
2. Open the notebook in Google Colab.
3. Follow the instructions in the notebook to complete the exercises.
